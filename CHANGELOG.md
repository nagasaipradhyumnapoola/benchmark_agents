# Changelog

## Unreleased — 0.1.0 development

- Product renamed to Bench Agents; canonical `bench-agents` CLI and `BENCH_AGENTS_*` settings, with legacy aliases retained.
- Guided terminal with original bold banner, model/agent setup, live progress, verified result tables, comparison and ZIP export.
- Empty startup inventory; explicit demonstrations and isolated verification workspaces.
- Website onboarding, endpoint and agent forms, native/controlled mode separation, one-task setup and clearer result interpretation.
- Validation responses omit rejected input values to avoid repeating accidentally pasted credentials.
- Versioned model, agent, task, verifier, trace, manifest and result contracts.
- SQLite-backed experiments, queues, immutable manifests, cancellation/recovery and artifacts.
- Real OpenAI-compatible/Ollama protocol adapters, opt-in native process adapters and independently verified public tasks.
- Zero-credential deterministic pipeline demonstration with negative cases.
- REST API, Python SDK, CLI and graphite Next.js research workspace.
- Statistical comparison, trace inspection and JSON/CSV/HTML/evidence-bundle exports.

This is not a V1.0 release declaration. See the requirements traceability and audit evidence for exercised behavior, limitations and remaining gates.
