# Agent Hub extension plan and contracts

User added: make this an agent hub where developers publish agents, discover recommended models, import agents in one click, benchmark them and share outcomes. Preserve current main-only push workflow and all previously authorized matrix/community work.

## Architecture and safety

Build a standalone shared registry service, separate from private benchmark execution. Default local registry port 8100, existing lab API 8000 and web 3000. The lab proxies `/api/hub/*` to the configured `BENCH_AGENTS_HUB_URL` (default http://127.0.0.1:8100). Standalone service mounts only `/v1` registry routes; it never exposes local models, credentials, execution or report files. This code is self-hostable; no hosted public deployment or fabricated users/agents is claimed. Existing GitHub-reviewed Community suggestions remain available.

One-click import means downloading an immutable text-source release, validating its digest and paths, staging code and registering a subprocess harness. Import does not run source, install dependencies or load model weights. Explicit trusted-agent host execution and configured model credentials remain separate. API keys never enter hub releases or published benchmark summaries.

## Shared release contract

`AgentManifest`: slug (lowercase slug), name, summary, readme, version (safe semver), license, runtime (`python`/`node`), entrypoint (relative text source path), args (string array), model_flag (optional), model_base_url_env (optional variable name), model_api_key_env (optional variable name), capabilities (default text), recommended_models (string array), benchmark_ids (string array), source_url (optional public HTTPS), dependencies (string array, informational), tags (string array).

`AgentRelease`: `{manifest: AgentManifest, files: Record<relative path, UTF-8 text>}`. Up to 40 files, 128 KiB per file, 1 MiB total; reject symlink-like/absolute/traversal/Windows-reserved/credential files, missing entrypoint, inline credentials and unknown fields. `release_digest(release)` is SHA-256 of canonical JSON of the validated manifest and files (sorted keys, UTF-8, compact separators). Releases are immutable.

## Hub service (backend worker)

Own new hub.py, hub_schemas.py, hub_store.py, tests/test_hub.py, docs/hub-server.md. `create_hub_app(data_dir=None)` and `app_factory()`; SQLite auth/agents/version/comments/reports. Passwords scrypt+random salt; opaque tokens stored hashed with expiry. Generic login failures, bounded login attempts, body caps and configurable trusted Host/Origin values; no auth provider dependency.

- GET `/v1/health` → `{status:'ok'}`
- POST `/v1/auth/register` and `/login` body `{username,password}` → `{token,user:{username}}`; POST `/logout`, GET `/me` require Bearer and return `{user:{username}}` for me.
- GET `/v1/agents?search=&model=&license=` → `{items:[{slug,name,summary,owner,latest_version,digest,license,recommended_models,tags,downloads}],total}`.
- POST `/v1/agents` AgentRelease → release detail (authenticated). Creator owns slug.
- GET `/v1/agents/{slug}` → `{slug,owner,latest_version,manifest,versions:[{version,digest,created_at}],downloads}`.
- POST `/v1/agents/{slug}/versions` AgentRelease → release detail; owner only, new immutable version only.
- GET `/v1/agents/{slug}/versions/{version}` and `/download` → `{slug,owner,manifest,files,digest,created_at}`. Download counts actual retrievals.
- GET/POST `/v1/agents/{slug}/versions/{version}/comments` → list / created `{id,author,body,created_at}`; post requires account.
- GET/POST `/v1/agents/{slug}/versions/{version}/reports` → list / created report; body `{model,benchmark_id,passed,total,evidence_url?}`; always force self_reported=true, validate passed<=total, never imply verified by hub.

## Website (frontend worker)

Own new agent-hub.tsx, app/hub/page.tsx, tests/agent-hub.test.tsx. Root owns sidebar/nav and existing other components. `/hub` and `?agent=slug&version=...`: browse/search, versioned agent detail, source/license/model guidance, code preview, import, account login/register/logout, publish text code files + manifest, owner new version, comments and clearly labeled self-reported benchmark summaries. No seeded examples, no blind code execution. Keep established readable graphite visual system and mobile/accessibility behavior.

Same routes under `/api/hub` with `/v1` removed. Lab proxy auth returns `{user}` and sets HttpOnly SameSite cookie; no token reaches frontend JS or storage. GET `/api/hub/auth/me` returns `{user:null}` when anonymous. GET `/api/hub/status` returns `{available,url,message}`. POST `/api/hub/import` body `{slug,version,expected_digest}` → `{agent:<Registration>,dependencies:[],source:{slug,version,digest}}`; button then links to experiment builder with returned agent ID. UI passwords clear and do not remain in query mutation variables. Publishing uses `{manifest,files}` contract above.
