# BenchLab implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement independent domain tasks; root owns coordination and commits. The user explicitly instructs autonomous implementation without a plan approval pause.

**Goal:** A local-first, verified AI benchmarking laboratory with a real engine, API/CLI and twelve integrated research screens.

**Architecture:** Versioned Pydantic contracts; SQLite event/result store; async orchestrator; independent verifiers; pluggable model/agent/environment adapters; Next.js REST client.

**Tech stack:** Python 3.12, FastAPI/Pydantic/Typer/httpx, SQLite, Next.js/React/TypeScript/Tailwind/shadcn/Radix/TanStack Query, Docker.

**Spec:** `docs/requirements.md`, `docs/architecture.md`, `docs/contracts.md`.

## Global constraints

No fabricated scores; demo labeling in UI and exports; no host execution of generated code; no stored secrets; credentials referenced by environment variable; actual dependencies and executable tests; black/graphite design; every commit pushed; no release-ready claim until five audit gates pass.

## Review focus

Cancellation during blocked network call; restart with active run; malicious artifact paths/symlinks and credential echoes; cross-condition comparisons; zero samples/provider usage unavailable. Pin each with tests in its owner's task.
